Methodology

How the AEO Readiness Score is calculated

The score combines six weighted categories. Each category contains transparent, label-every-check heuristics — not a black-box AI model.

25%

Answer Content

Direct-answer paragraph patterns, question coverage in headings, FAQ presence, internal link coverage, readability.

20%

Structured Data

JSON-LD detection, Organization / FAQ / Article / Breadcrumb schema, basic validation.

20%

Technical Crawlability

HTTPS, HTTP status, redirects, title, meta description, canonical, robots, heading hierarchy.

15%

Entity Signals

Organization identity (About/Contact), author byline, sameAs links, social profile coverage.

10%

Question Coverage

Explicit question-pattern headings mapped to your topic — a key answer-engine signal.

10%

Credibility

Visible content dates, language declarations, accessibility basics (image alt, html lang).

Important. This tool performs a real but heuristic analysis. It is not a guaranteed ChatGPT ranking score, a Google AI Overview inclusion guarantee, or a real-time AI-visibility metric. Some checks are unavailable for sites that block server-side fetching, require JavaScript rendering, or sit behind bot protection. FAQ

AEO Checker — frequently asked questions

Is the AEO Checker actually functional?
Yes. The checker performs a real server-side fetch using PHP cURL with SSRF-safe validation, then parses the returned HTML with DOMDocument/XPath. All checks reflect what we actually detected on the page. No mock data, no fake scores.
Why does my site score poorly?
Common causes: missing JSON-LD schema, no direct-answer paragraph pattern in opening content, no FAQ section, missing author byline, no canonical tag, missing image alt attributes, or blocked server-side fetching (Cloudflare bot protection, JS-only rendering). Each check shows its specific finding.
Will the checker trigger my analytics or break my site?
No. The checker makes a single HTTP GET request with a clearly identified user-agent. No JavaScript is executed, no forms are submitted, no interactions are simulated. It is no more impactful than a normal visitor landing on your page once.
Can I download the report?
A "Download report" link is included in every successful result. The download is a static HTML summary suitable for sharing internally. For a comprehensive report covering your full site, request a paid AEO audit.
Do you store the URLs I check?
We keep aggregated, non-identifying logs (URL host, score, timestamp) for service improvement and rate limiting. We do not store full page content, your IP, or any personal data tied to your check. See our privacy policy for details.
